# Solutions

Reference implementations for every step, mirroring the module layout.

**How to use them:** stuck for more than ~20 minutes → read the relevant solution →
close it → retype the idea from memory into your own step file. Copying a solution you
haven't re-derived puts the magic back into your pipeline, and magic is the thing this
whole track exists to remove.

To *run* a solution file, copy it over your step file inside the module directory
(paths are relative to the module root):

```bash
cp solutions/module1_weather/step3_retrieve.py module1_weather/step3_retrieve.py
```
